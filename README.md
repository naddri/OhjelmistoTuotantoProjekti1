# Online Flashcard System

A simple flashcard app for studying. Students can make their own flashcards and teachers can share study materials.

## What is this?

This is our group project where we're building a flashcard application. Students can create flashcards to study, and teachers can upload flashcard sets for their classes.

## What we're using

- **JavaFX** - For the user interface
- **MariaDB** - Database to save everything

## Features we're building

**For Students:**
- Make your own flashcards and quizzes
- Study with flashcards

**For Teachers:**
- Upload flashcard sets for different subjects
- Share study materials with students
